# 🎵 左耳

> 一个有点好用的桌面音乐播放器

## 下载

👉 **[v1.2.0 正式版](https://github.com/Li7ky/AurisLeft/releases/tag/v1.2.0)** · Windows 安装包

## 能干啥

- 🔍 **搜歌**：多平台聚合，一次搜遍网易/酷我/酷狗/QQ
- 🎶 **播放**：队列、随机、循环，该有的都有
- 📁 **本地**：扫描文件夹，离线也能听
- ❤️ **收藏**：喜欢的歌，一键收藏
- 📋 **歌单**：整理你的音乐库
- 🌙 **睡眠定时**：设个时间，到点自动停
- 🎨 **主题换肤**：暗色/明亮，随你心情
- 💾 **数据备份**：导出导入，换电脑不丢

## 怎么用

1. 下载安装，打开
2. 顶部搜歌，点一首就播
3. 左侧看收藏/歌单/本地，右下角看歌词
4. 设置里改主题、下载目录、备份数据

> 💡 个别歌播不了？自动换源试试。还不行？换一首呗。

## 开发

```bash
npm install
npm run dev   # 开发
npm run dist  # 打包
```
